# Ultra Brave

A fast, private web browser for Windows with built-in ad and tracker blocking.

**[Download the latest version](https://github.com/lagonman9-crypto/ultra-brave/releases/latest)**

## Install
1. Download `UltraBrave.zip` from the latest release.
2. Right-click it, choose **Extract All**, then open `UltraBrave.exe`.
3. If Windows SmartScreen warns you, click **More info** then **Run anyway** (the app isn't code-signed yet).

## Requirements
- Windows 10 or 11, 64-bit
- [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)
- [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) (already on Windows 11)

`index.html` in this repo is the download page.
