Installing

There's no installer. Ultra Brave runs from the folder you put it in.

  1. Unzip

    Right-click UltraBrave.zip, choose Extract All, and put the folder somewhere like Documents.

  2. Open

    Double-click UltraBrave.exe in the folder. Pin it to your taskbar so it's easy to find.

  3. If Windows warns you

    The app isn't code-signed yet, so SmartScreen may stop it. Click More info, then Run anyway.
